Planificación editorial visual

Arma la semana y mira cómo se verá antes de publicar.

Editorial Emulator sirve para organizar contenidos por día, probar distintas combinaciones y ver cómo quedarían en Instagram, TikTok, LinkedIn, YouTube y Facebook sin perder el plan original.

¿Qué problema resuelve?

El problema no es sólo “tener un calendario”. El problema es poder decidir qué publicar, en qué orden y cómo se sentirá ese conjunto de piezas cuando llegue a cada red.

Planear en listas se vuelve confuso

Cuando hay muchas piezas, un spreadsheet o una lista deja de mostrar la carga real de cada día y cuesta reorganizar rápido.

No ves el efecto del conjunto

Puedes tener buenos posts individualmente y aun así terminar con una semana repetitiva, saturada o mal balanceada.

Mobile y desktop se sienten distintos

Una grilla o feed puede funcionar en teléfono y verse mal en desktop. El emulador permite revisar ambos contextos.

Cómo lo resuelve

Un solo plan, 3 vistas

Board, Timeline y Agenda trabajan sobre los mismos datos. Cambiar de vista no crea copias ni borra el escenario.

Varias formas de añadir contenido

Puedes arrastrar, tocar “Añadir a…” o entrar directamente al día y seleccionar la pieza.

Feeds simulados

El mismo plan se convierte en representaciones de Instagram, TikTok, LinkedIn, YouTube y Facebook para revisar ritmo y distribución.

Cómo funciona, simple

Creas o abres un escenario

Un escenario es una versión de tu semana. Puedes partir de una base, empezar vacío o duplicar otro.

Organizas la semana

Colocas cada pieza en lunes, martes, miércoles, etc. Puedes moverla, reordenarla, eliminarla o deshacer con Undo.

Pruebas las 3 vistas

Board para arrastrar, Timeline para comparar densidad y Agenda para ajustes precisos.

Revisas los feeds

Seleccionas una plataforma, Mobile o Desktop, y cambias entre Grid, Feed o Player según la red.

Las 3 vistas del planificador

1 · BOARD

Tipo Trello

Los 7 días aparecen como columnas. Es la vista más visual para arrastrar contenidos y moverlos entre días.

Contenido → mantener pulsado → arrastrar → día → soltar
2 · TIMELINE

Semana compacta

Cada día es una fila. Sirve para revisar rápidamente qué tan cargado está cada día y el orden de las piezas.

Lun [A] [B] [C]
Mar [A] [B]
Mié [A] [B] [C] [D]
3 · AGENDA

Precisión

Lista cada pieza por día y permite subir, bajar, mover o eliminar sin depender del gesto de drag.

09: pieza 1 ↑ ↓
10: pieza 2 ↑ ↓
11: pieza 3 ↑ ↓

Qué puedes revisar en cada red

Instagram

Grid, Feed y Reels. Útil para revisar ritmo visual, repetición de formatos y balance de piezas.

TikTok

Grid y feed vertical. Permite recorrer las publicaciones como una secuencia.

YouTube

Grid, Videos y Player. Los contenidos horizontales se ven con más espacio en desktop.

LinkedIn

Grid y Feed para revisar notas, videos, carruseles y densidad editorial.

Facebook

Grid y Feed para comprobar distribución y mezcla de formatos.

Mobile / Desktop

El mismo escenario se ve en ambos tamaños sin duplicar ni modificar datos.

Configuración

1. Supabase

La URL y la clave pública ya están configuradas en la app. Para sincronizar datos privados sólo debes iniciar sesión desde el indicador Cloud dentro de la app.

Cloud · iniciar sesión → email + contraseña → workspace: editorial-os → sincronización automática

2. PWA en iPhone

Abre la app en Safari y usa Compartir → Añadir a pantalla de inicio. Se abrirá como aplicación independiente.

Safari → Compartir → Añadir a pantalla de inicio → Editorial Emulator

3. Desktop Mac

Puedes descargar la versión Desktop. Abre la misma aplicación pública dentro de una ventana WebKit independiente.

Descargar para Mac

4. Datos y actualizaciones

La UI trabaja localmente primero para responder rápido. Después sincroniza con Supabase. La versión Desktop carga GitHub Pages, por lo que los cambios de la app web llegan sin reinstalar el wrapper.

Arquitectura simple

Editorial Emulator ├─ Web / PWA iPhone ├─ GitHub Pages ├─ Desktop Mac (WKWebView) │ ├─ localStorage → respuesta inmediata └─ Supabase → sincronización compartida Mismo escenario → Plan → Board / Timeline / Agenda → Feeds → Instagram / TikTok / LinkedIn / YouTube / Facebook

Preguntas frecuentes

¿Si cambio de Board a Agenda pierdo lo que hice?

No. Las tres vistas trabajan sobre el mismo escenario y los mismos datos.

¿Tengo que arrastrar todo?

No. Puedes usar “Añadir a…” o el botón + de cada día. El drag es una opción, no un requisito.

¿Funciona sin internet?

La parte local puede seguir funcionando. La sincronización con Supabase se reanuda cuando vuelve la conexión.

¿La app de Mac es otra versión?

No. Es un wrapper nativo ligero que carga la misma versión pública de GitHub Pages.

¿Dónde se guardan los datos?

Primero se guardan localmente para que la interfaz responda rápido. Si conectas Supabase, también se sincronizan con el workspace editorial-os.
