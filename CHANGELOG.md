# Editorial Emulator V1

- App estática independiente sólo para emulación.
- Plan semanal en desktop y día activo en móvil.
- Catálogo de contenido compartido con Editorial OS.
- Play/Pause de simulación con recorrido de ocurrencias.
- Feeds completos para Instagram, TikTok, LinkedIn, YouTube y Facebook.
- Instagram Perfil de 3 columnas y Feed vertical.
- Scroll real dentro del mockup del teléfono.
- Visor expandido a pantalla completa.
- Formularios simplificados para contenido, pilares, familias y marcas.
- Supabase compartido con merge sobre payload remoto actual.
- Escenarios compartidos.
- PWA y Service Worker con scope separado.
