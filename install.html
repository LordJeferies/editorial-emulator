Instala Editorial Emulator desde cero.

Esta página te da el instalador para reinstalar la app Desktop, descargar la repo actual y configurar el MCP. Tus datos de Supabase y la app web no se borran.

Qué instala

  • Editorial Emulator.app
  • repo local en ~/Downloads/editorial-emulator
  • servidor MCP
  • launcher MCP seguro
  • dependencias Node 20+ si Homebrew está disponible

Qué NO borra

  • datos en Supabase
  • la versión Web/PWA
  • GitHub Pages
  • tu repo remoto
1 · desbloquear

Introduce la clave de instalación

↓ Descargar instalador

La clave de esta página es sólo una barrera de conveniencia. Como la página y el script son públicos, no debe tratarse como un mecanismo de seguridad real.

Descarga el instalador

Después de poner la clave correcta aparecerá el botón de descarga.

Ejecuta en Terminal

cd ~/Downloads chmod +x Editorial-Emulator-Installer.sh ./Editorial-Emulator-Installer.sh

Vuelve a introducir la clave

El instalador también valida la clave antes de limpiar la instalación anterior.

Configura Supabase MCP

Durante el setup MCP te pedirá email y contraseña de Supabase. Se guardan en Keychain, no en GitHub.

Alternativa: instalar directo desde Terminal

Si no quieres descargar manualmente el archivo, usa:

cd /tmp curl -fL https://raw.githubusercontent.com/LordJeferies/editorial-emulator/main/install-from-zero.sh -o editorial-emulator-install.sh chmod +x editorial-emulator-install.sh ./editorial-emulator-install.sh
