Cómo usar la app

Trabaja visualmente, cambia de vista sin perder nada y usa Cloud/MCP cuando quieras automatizar.

Quiero empezarEn la bienvenida pulsa “Entrar a la app”. Luego abre un escenario o crea uno nuevo.
Quiero armar la semanaPlan → Board, Timeline o Agenda. Las 3 vistas editan exactamente el mismo plan.
No quiero arrastrarUsa “Añadir a…” en un contenido o “+ Añadir” dentro del día. El drag es opcional.
Quiero reorganizarMueve entre días, reordena, usa Undo/Redo o duplica el escenario antes de experimentar.
Quiero revisar feedsFeeds → plataforma → Mobile/Desktop → Grid/Feed/Player según la red.
Quiero saber si está cargandoMira la barra superior: muestra porcentaje y qué operación está haciendo la app.
¿La app se bloquea al cargar?No normalmente. Las operaciones siguen en segundo plano. Si una acción necesita bloquearse, verás un aviso explicando por qué debes esperar.
Quiero sincronizarPulsa el indicador Cloud, inicia sesión en Supabase y la app sincronizará el workspace editorial-os.
Quiero usar MCPPulsa MCP en la barra superior o abre la guía MCP. Permite manejar escenarios, planner, contenido, feeds y backups desde un agente compatible.
Quiero recuperar un cambio MCPEl MCP guarda backups automáticos antes de mutaciones. Puede listar y restaurar esos backups.
Quiero la app para MacDescarga Editorial Emulator.app. Abre esta misma GitHub Page dentro de una ventana WebKit independiente.
No tengo internetEl trabajo local sigue disponible. Cloud/MCP requieren conexión para sincronizar Supabase.
