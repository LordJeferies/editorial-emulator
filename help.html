Cómo usar la app

Elige lo que quieres hacer y sigue el flujo correspondiente. La app trabaja localmente primero; Supabase sincroniza después y nunca es requisito para abrir, crear o editar.

Quiero continuarEn Inicio abre el escenario reciente o entra en “Usar escenario existente”. Todo cambio se guarda de inmediato en local.
Quiero crear desde cero“Crear escenario nuevo” → Semana vacía. Después arrastra o toca contenidos desde la bandeja inferior.
Quiero partir de JOC“Crear escenario nuevo” → Base JOC. Conserva la estructura fija y reemplaza sólo lo necesario.
Quiero probar una campañaDuplica un escenario existente para crear una variante A/B sin destruir el original.
Quiero reorganizarArrastra piezas entre días o usa el menú •••. Undo/Redo recupera añadir, eliminar, mover, vaciar y cambios de semana.
Quiero empezar limpio“Borrar todo” pide confirmación y puede recuperarse inmediatamente con Undo.
Quiero revisar InstagramFeeds → Instagram → Mobile/Desktop → Grid, Feed o Reels. El escenario no cambia cuando cambias de visor.
Quiero revisar TikTokUsa Grid para ver distribución y Feed para recorrer publicaciones verticales con título, tipo, fecha y nivel.
Quiero revisar YouTubeAlterna Grid, Videos y Player. Los horizontales y el reproductor tienen más espacio en Desktop.
Quiero presentar el escenarioPulsa Play y usa anterior/siguiente para recorrer ocurrencias. “Ver feed” salta a la plataforma de la publicación activa.
Quiero encontrar algo rápido⌘K / Ctrl+K abre Acciones rápidas. / enfoca búsqueda de contenidos. 1, 2 y 3 cambian Plan, Feeds y Biblioteca.
No tengo internetPlan, escenarios, Undo/Redo y visores siguen funcionando. El estado de sincronización muestra Offline hasta recuperar conexión.
Quiero la app para MacEn Inicio pulsa “Descargar para Mac”. Recibirás Editorial Emulator.app dentro de un ZIP. Es un wrapper WebKit de esta misma URL pública, por lo que la interfaz web se actualiza sin reinstalar el programa.
¿Web y Desktop son dos apps?No. GitHub Pages es la aplicación canónica. La PWA móvil, Safari Web App y Editorial Emulator.app cargan la misma versión publicada; Supabase mantiene los datos compartidos.
Desktop macOS · requiere macOS 13 o posterior. El build público es firmado ad-hoc; si macOS aplica cuarentena, usa el instalador incluido en el repo o el comando de Terminal indicado en README.
