EDITORIAL EMULATOR V3.2 · ACTUALIZAR + MCP
==========================================

1) ACTUALIZAR REPO LOCAL

cd "$HOME/Downloads/editorial-emulator"
git stash push -u -m "backup-auto-$(date +%Y%m%d-%H%M%S)" || true
git config core.fileMode false
git fetch origin
git checkout main
git reset --hard origin/main

2) INSTALAR / VALIDAR MCP

cd "$HOME/Downloads/editorial-emulator/mcp"
chmod +x install.sh
./install.sh

3) VARIABLES QUE DEBES CONFIGURAR EN TU CLIENTE MCP

EDITORIAL_SUPABASE_EMAIL=TU_EMAIL
EDITORIAL_SUPABASE_PASSWORD=TU_PASSWORD
EDITORIAL_WORKSPACE=editorial-os

La URL y la anon/public key se leen automáticamente desde:
$HOME/Downloads/editorial-emulator/supabase-config.js

NO uses ni guardes en el repo:
- service_role
- database password
- secret keys
- GitHub PAT

4) ABRIR APP DESKTOP

open "/Applications/Editorial Emulator.app"
