Model Context Protocol · V3.2

La app completa, controlable desde un agente.

El MCP permite leer y modificar Editorial Emulator desde ChatGPT, Codex, Claude u otro cliente compatible usando el mismo Supabase que Web, PWA y Desktop.

Arquitectura

Agente MCP ↓ stdio Editorial Emulator MCP local ↓ usuario Supabase public.editorial_state workspace_key = editorial-os payload = version 9 ↓ Realtime Web / PWA / Desktop Mac

Instalación

1. Instalar servidor

cd ~/Downloads/editorial-emulator/mcp chmod +x install.sh ./install.sh

Requiere Node.js 20+.

2. Configurar cliente MCP

{ "mcpServers": { "editorial-emulator": { "command": "node", "args": ["/Users/TU_USUARIO/Downloads/editorial-emulator/mcp/server.mjs"], "env": { "EDITORIAL_SUPABASE_EMAIL": "TU_EMAIL", "EDITORIAL_SUPABASE_PASSWORD": "TU_PASSWORD", "EDITORIAL_WORKSPACE": "editorial-os" } } } }

Credenciales

La URL y la anon/public key se leen de supabase-config.js. No uses service_role, database password, secret keys ni GitHub PAT.

Herramientas

ESTADO

Status y validación

editorial_status, editorial_get_capabilities, editorial_validate_state.

ESCENARIOS

Crear y administrar

Listar, leer, crear, duplicar, renombrar y eliminar.

PLANNER

Modificar la semana

Añadir, mover, reordenar, eliminar, limpiar y aplicar batches.

BIBLIOTECA

Contenido y taxonomía

Contenido personalizado, marcas, pilares y familias.

FEEDS

Preview por plataforma

Deriva ocurrencias para Instagram, TikTok, LinkedIn, YouTube y Facebook sin modificar el plan.

RECUPERACIÓN

Backups MCP

Cada mutación crea backup automático. Se pueden listar y restaurar.

Criterios

Antes de escribir

  • leer estado actual;
  • usar IDs reales;
  • evitar duplicados;
  • separar análisis y ejecución en cambios grandes.

Al modificar

  • usar batch para cambios relacionados;
  • preservar campos desconocidos;
  • confirm=true en operaciones destructivas;
  • validar después de cambios grandes.
